# Stage document (Archify) — the `## docs` step of plan, design, build and review

Each stage ends with a document the acceptor can see: an Archify diagram delivered as standalone HTML under
`<home>/<slug>/docs/` (plan `architecture` from intent.md, design `dataflow` from spec.md, build `workflow` from
plan.md, review `sequence` from review.md and test-report.json).

1. Author `<home>/<slug>/docs/<stage>.json` by the Archify skill's fast path (`~/.claude/skills/archify/SKILL.md`:
   read the type's `schemas/<type>.schema.json`, `schemas/common.schema.json` and one `examples/*.<type>.json`,
   nothing else). Draw what the stage artifact says, not what you remember: one main path, at most 12 primary
   nodes, `meta.quality_profile: "showcase"`, no subtitle, and one summary card whose first item is
   `Generated by CrewForge5 from <stage> sources @ <first 12 chars of source_digest>; drafts are Claude's reading
   of the artifact, the acceptor decides` (`crewforge5 docs check <stage>` reports `source_digest`).
2. `crewforge5 docs render <stage>`. On `archify deliver exited`, repair the JSON source only, at most two rounds,
   then report the diagnostics verbatim. A `skipped` verdict (docs off, no Node, no Archify skill) means go on
   without the document: say so in one line. Never run Archify's update checker, `preview` or `visual-check`
   inside a stage; documents are never rendered from a hook.
3. `crewforge5 docs open <stage>` shows the HTML (never under CI). Quote its path in the acceptance question, and
   say so when the verdict carries `artifact_matches: false` (the HTML on disk is not the bytes Archify delivered).

`plan|design|build accept` and `review review` are refused while the document is missing or stale against its
sources (the `Status:` line is masked, so accepting never stales it). After editing the artifact, render again.
Install Archify with `npx -y skills add tt-a1i/archify --skill archify --agent claude-code --global --copy --yes`
(Node >= 18), or set `[knowledge] auto_install = true` and run `crewforge5 knowledge bootstrap`.
